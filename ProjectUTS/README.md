## Cara Run program
- Lakukan git clone https://github.com/Frontend-Kelompok5-KelasA/Frontend-Programming-Kel5/tree/main/ProjectUTS pada terminal
- Pastikan direktori pada terminal sudah berada di dalam folder ProjectUTS
- Jalankan perintah npm run dev pada terminal, lalu tunggu sampai program memberikan link url untuk diakses pada halaman browser. Jika program memberikan url seperti ini: Silahkan buka http://localhost:8080 untuk mengakses website, maka program berhasil dijalankan
